Telepath

Local-first cognitive thought capture and thread evolution graph.

Publisher: Ayengee Labs • Platform: Android • Status: Early Access

Get on Google Play

Key Specifications & Features

Directed Acyclic Graph (DAG) Structuring

Automatically organizes fragmented thoughts and iterative ideas into linked parent-child trees without artificial hierarchy limits.

Local-First Encryption

Data remains 100% on-device using encrypted Room / SQLite persistence with SQLCipher. Zero mandatory cloud egress.

Idempotent Task Sync

Bi-directional Markdown and JSON export engine designed to never overwrite completed tasks or lose revisions.

Private Google Drive Sandbox

Optional backup using the isolated user Google Drive AppData folder without developer server tracking or central database logging.
